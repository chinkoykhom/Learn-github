# Learn-github

เป๊ปซี่ (Pepsi) คือเครื่องดื่มน้ำอัดลมรสโคล่าระดับโลก ผลิตโดยบริษัท PepsiCo จากสหรัฐอเมริกา มีประวัติยาวนานกว่าศตวรรษ เริ่มต้นจากร้านขายยาในปี 1890s และเป็นคู่แข่งสำคัญของโคคา-โคล่า มีหลากหลายรสชาติและผลิตภัณฑ์ภายใต้แบรนด์ โดยมีสโลแกนที่เน้นความสดชื่น, ความมั่นใจ และการใช้ชีวิตทันสมัย
